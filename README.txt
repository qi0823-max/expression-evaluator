# 表达式求值与逆波兰转换 (Expression Evaluator)

## 📌 项目简介
数据结构课程设计，实现多位数、小数、括号及一元负号的表达式求值，支持中缀转后缀（RPN），并扩展了表达式树遍历功能。

## 👥 小组分工
*   **组长 (wzq)**：主控菜单、中缀转后缀核心算法、表达式树扩展、代码集成。
*   **组员 (zyh)**：词法扫描模块（多位数/小数/非法字符/负号）、M1测试数据。
*   **组员 (lxy)**：后缀求值模块、异常处理（除零等）、优先级表封装。
*   **组员 (lx)**：括号匹配、Trace追踪、批处理功能、交叉测试、报告/PPT。

## 🛠️ 开发规范
*   所有接口定义见 `expr.h`。
*   **分支规范**：不要在 `main` 分支直接提交！所有人建自己的 `feature-xxx` 分支，写完提交 PR (Pull Request)，由组长审核合并。
*   **Commit 规范**：`feat: 增加xx功能` / `fix: 修复xxbug` / `docs: 更新文档`。
